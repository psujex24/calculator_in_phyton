Kalkulator w Pythonie 🧮

Prosty kalkulator stworzony w języku Python z wykorzystaniem biblioteki `tkinter`. Projekt powstał jako forma eksperymentu i pierwszego kontaktu z Pythonem – miałem na celu sprawdzenie, czy ten język programowania mi odpowiada.

🎥 Demo

Zobacz działanie aplikacji na YouTube:  
https://youtu.be/boGKIR1N4Dk

📦 Wymagania

- Python 3.x  
- Biblioteka `tkinter` (standardowo dołączona do Pythona)

🚀 Uruchamianie

1. Sklonuj repozytorium:
   git clone https://github.com/psujex24/calculator_in_phyton.git
   cd calculator_in_phyton

2. Uruchom plik:
   python main.py

🛠 Funkcje

- Interfejs graficzny oparty na `tkinter`
- Podstawowe operacje: dodawanie, odejmowanie, mnożenie, dzielenie
- Przycisk `C` do wyczyszczenia działania

⚠️ Znane ograniczenia

Ponieważ był to projekt testowy, aplikacja zawiera pewne niedociągnięcia:

- Brak walidacji danych – można wpisywać dowolne znaki, co może prowadzić do błędów
- Możliwość usunięcia całego działania, co może powodować wyjątki
- Znakowe błędy wizualne (np. mieszanie się operatorów)

Nie planuję dalszego rozwijania tego projektu – był to raczej jednorazowy eksperyment.
